## Memory of an open document

Resident memory of the process right after a file is opened, with the document still open. *Heap* is anonymous memory: what a parsed tree takes, and what has to be paid for out of the machine's RAM and swap. *Mapped file* is the file's own pages, which belong to the page cache and are given back whenever memory is wanted. *Peak heap* is the highest heap during the open itself.
